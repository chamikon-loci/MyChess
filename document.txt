Tech Stack : 
React.js สำหรับหน้า UI ฝั่ง Client
Express.js(Node.js) สำหรับการสร้าง Server REST API
PostgreSQL สำหรับเก็บข้อมูล [ไม่เอาละ ขี้เกียจทำ แค่ทำเกมก็โคตรยากละ]
Socket.io สำหรับ Real-time communication ระหว่าง Clients กับ Server
CORS สำหรับให้ฝั่ง Client ติดต่อกับ Server ได้จากคนละ Origin
Render สำหรับการ Deploy

ตัวเกมหมากรุก
- ตาราง 8x8
- การเดินหมากตามกฏของแต่ละตัว
- กฏการกิน
- กฏการเข้าป้อม [ช่างมันก่อนก็แล้วกันน้าาา]
- กฏ En Passant [ช่างมันก่อนก็แล้วกันน้าาา]
- กฏการ Check
- กฏการ Checkmate
- กฏการ Promotion
- กฏการ Draw/Statemate

การสร้างห้องเกม
- สร้างห้อง 1v1
- แสดงห้องที่หน้า UI ให้กด Join
- ในห้องมีครบสองคนแล้วเจ้าของห้องกด Start
