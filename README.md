## Demo
Play MyChess.com: https://my-chess-blond.vercel.app/

## Features
- Real-time 1v1 multiplayer chess
- Create and join chess rooms (no disconnection yet)
- Turn-based gameplay 
- Chess piece movement
- Capturing
- Check detection
- Checkmate detection
- Stalemate detection
- Pawn promotion

## How to Run
### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/MyChess.com.git
cd MyChess.com
```
### 2. Install backend dependencies
```bash
cd backend
npm install
```
### 3. Run Backend Server
```bash
npm run dev
```

SAME SAME TO frontend Folder

Then open: http://localhost:5173
